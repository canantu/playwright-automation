Week02- Review: 

- setup playwright: npm init playwright@latest

- spec (test)files naming convention: playwright-practice.spec.js

- package.json:
    - 2 dependencies: dev and general 
    - store scripts:
        - scripts can be run with npm run ${script-name}
        for example: npm run tests / npm run test:specific

- playwrith.config.js
    - how to deal with flaky test: configure retries in global config (playwright.config.js)
    - use option: 
        -trace: off/on/on-first-retry/retain-on-faliure
        we would like to trace failed tests only
        if set on;  on the report, there will appear a view trace button, it will show a screenshot for every single step, it includes before and after hooks.
        it shows the full snapshot of the dom. it saves also the network activities. 
        - if test is running locally, set the retries=1

        - headless: true, we dont want to set this static, take it off,
        if you take it off, it automatically runs in headles mode
        use this instead in scripts in package.json ->   "tests:headed": "npx playwright test --headed"

- uninstall dependencies: npm uninstall --save-dev @faker-js/faker
- dev dependencies and dependencies -> dev vs prod

- any dependency action can be done via node dependencies extension

- to use local browsers, in global config add this:
{
      name: "Google Chrome",
      use: {
        ...devices["Desktop Chrome"],
        channel: "chrome",
        viewport: { width: 1280, height: 720 },
      },
},

- you can slow down the test steps with launchOptions and video will be easy to watch when debugging
    launchOptions: {
      headless: false,
      slowMo: 2000, // Slow down by 2 seconds to see the actions
    },

- for personal debug trace is enough, if you want to collect evidence for a failing test you can add screenshot and video separately

- test in real mobile device: 
    name: "Mobile Chrome",
      use: {
        ...devices["Galaxy Note 3"],
      },
